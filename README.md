# STM32G431 + DRV8316 万向节云台无刷FOC控制器
> 嵌入式学习项目，4015FOC有感云台驱动，AS5600磁编码器角度采集，ADC电流采样、CAN、串口调试

## 🧩 硬件方案
- 主控：STM32G431
- 驱动芯片：DRV8316（SPI配置，nFAULT故障检测 PB4）
- 角度传感器：AS5600 I2C磁编码器
- 电流采样：ADC1采集三相电流 SOA/SOB/SOC + 母线电压 + 电位器调速
- 外设资源：
  - TIM1 互补SVPWM，带死区
  - SPI1 通信DRV8316
  - USART1 串口调试打印（PB6/PB7）
  - FDCAN1 通信（PA11/PA12）

## ⚠️ 使用提醒
1. 本项目仅**学习交流用途**，不适合直接商用；功率电路存在触电风险，上电前务必检查短路
2. DRV8316需要注意上电顺序、FAULT故障排查
3. 使用前必须完成电流采样校准、编码器零点校准
